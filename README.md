#National-ID-Insight

The NIC Decoder App is a mobile application built using Flutter that allows users to decode Sri Lankan National Identity Card (NIC) numbers and retrieve valuable information such as:

Date of Birth
Age
Gender
Weekday of Birth
NIC Format (Old/New)
Serial Number
Voting Eligibility

#Features

NIC Input Field: Users can input an NIC number, and the app will decode it to provide important details.
User-friendly UI: Modern dark-themed design with a gradient background and stylish components.
Instant Feedback: Provides real-time error notifications if the input NIC is invalid.
Gender & Voting Eligibility: The app determines the gender based on the NIC and checks voting eligibility.
Cross-Platform: Built using Flutter to work seamlessly on both Android and iOS.

#Tech Stack

Flutter: Cross-platform mobile app development framework.
intl Package: For formatting dates and time.
Dart: Programming language used for Flutter development.
